# SENDA · Córdoba a pie — web en borrador

Esta es la **web generada** de SENDA, publicada con GitHub Pages para recoger comentarios:
https://me1catrr.github.io/senda-web/

- Es un **borrador para revisión**. La ruta «La Breña – Río Cabrilla» está pendiente de reconocer y la web
  **no es una guía de navegación**.
- El contenido fuente y el código de generación viven en un repositorio privado; aquí solo está el resultado.
- Cada dato lleva su sello de certeza y sus fuentes. Las ilustraciones son esquemas propios; las imágenes de
  terceros, si las hay, indican autoría y licencia en sus pies de foto.
